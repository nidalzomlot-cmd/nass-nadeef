# نَصّ نظيف

أداة عربية مجانية لتنظيف النصوص المنسوخة من ChatGPT وClaude وGemini قبل لصقها في واتساب أو وورد أو فيسبوك.

- حذف `**` و`#` و`---` وتحويل الجداول لأسطر
- تحويل لتنسيق واتساب (`*عريض*`، `_مائل_`)
- تصحيح الترقيم العربي (، ؟ ؛) بجانب الكلمات العربية فقط
- تبديل الأرقام، حذف التشكيل/التطويل/الإيموجي/رموز الاتجاه المخفية

كل المعالجة داخل المتصفح، بدون سيرفر.

## النشر
Settings → Pages → Deploy from branch → `main` / root.

## AdSense
بعد القبول، فك التعليق عن سطر AdSense في `<head>` بكل صفحة وضع رقم الناشر `ca-pub-...`، وأضف `ads.txt` في الجذر.
